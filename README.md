## המסלול

מתחילים בכניסה הראשית - קוד הפתיחה מופיע על מסכי הטלוויזיה - ומסיימים באולם שביט,
ליד קיר העבודות ושולחן השיחות האישיות.

1. גובה העיניים - הקיר משמאל לעמדת השומר
2. מסדרון הכניסה
3. איפה מישהו התפשר - אזור המדרגות והפאטיו
4. איפה הצפון - במרכז החצר, מול קיר המעליות
5. המדרגות לפאטיו
6. לזהות חומר ביד - הארון הצהוב ליד אולם שביט
7. עבודות הסטודנטים - קיר העבודות באולם שביט

סורקים ברקוד אחד בכניסה - הוא מופיע גם על מסכי הטלוויזיה בלובי - וכל השאר עובד
מהנייד. לשלטי התחנות אין ברקוד. אפשר עדיין לקפוץ ישירות לתחנה עם `?s=3` וכן הלאה,
למי שמצטרף באמצע.

שלטי התחנות נושאים רק מספר, לוגו, כותרת, והשורה שההוראות כבר בנייד - כדי שייקראו
מרחוק ולא יתחרו במסך.

מה שצריך להיות פיזית בשטח: **סרט מדידה בתחנת המדרגות**, ו**סרגל הקיר** לתחנת גובה
העיניים - `sargel-print.pdf`, גיליון אחד 400×1700 מ״מ להדפסה 1:1 בבית דפוס.
כשהגיליון חוזר, מדדו את רוחבו: 40 ס״מ בדיוק פירושו שקנה המידה נכון.
`/sargel` הוא אותו סרגל בשישה דפי A4, לגיבוי.

## טופס ההרשמה

**מחובר ופעיל.** הטופס בסוף המסלול שולח לגיליון Google של המכללה דרך ה-Apps Script
שב-`apps-script.gs`, וכתובת ה-Web app יושבת במשתנה `ENDPOINT` בראש `index.html`.
אין מפתחות סודיים בקוד הדף - כתובת ה-Web app פומבית בהגדרתה.

מה נשמר בכל שורה: תאריך, שם, טלפון, אימייל, אישור יצירת קשר ונוסח ההסכמה,
מספר התחנות שהושלמו, התשובות מכל התחנות, וקישור לצילום מתחנת הפשרות שנשמר בדרייב.
במקביל נשלחת התראה במייל ל-`daniel@cts.org.il`.

נבדק מקצה לקצה ב-17.8.2026: שליחה מלאה עם צילום, דחיית פנייה ללא אישור יצירת קשר,
ועמידות בקלט פגום. השורה נחתה בגיליון והמייל הגיע.

אחרי כל שינוי ב-`apps-script.gs` צריך לפרוס גרסה חדשה
(Deploy ← Manage deployments ← עריכה ← Version: New version), אחרת הכתובת
ממשיכה להריץ את הגרסה הישנה.
